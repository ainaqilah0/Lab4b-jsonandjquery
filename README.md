# Introduction
This lab focuses on creating JSON data, retrieving JSON information using JavaScript fetch() API, and performing DOM manipulation using jQuery.

# Question 1: Create and structure JSON data
In this question, I created a JSON file named books.json to store information about two books. I also validated the JSON file using JSON validator to ensure that there were no syntax error.

# Question 2: Retrieve and display JSON data
In this question, I created books.html to retrieve book information using JavaScript fetch() API. The information was displayed on the webpage using textContent and error handling also included.

# Question 3: Compare native JavaScript and jQuery
In this question, I created jquery-dom.html to perform DOM manipulation using jQuery. Besides that, .text() s used to modify the text, .addClass() to apply CSS styling, .on() to handle the button click event.
